# Licensing and governance authorization

HD-012 is resolved for OpenC 1.0. The project owner selected and locally
recorded:

- CC0-1.0 for normative and informative specification text, documentation,
  schemas, metadata, diagrams, and artwork;
- 0BSD for the implementation, runtime, libraries, tools, tests, examples,
  release programs, and executable conformance fixture source;
- inbound contribution terms matching the applicable outbound terms, without
  a CLA;
- owner authority for normative decisions, errata, security triage, release
  approval, checksums, and publication;
- a permissive name/artwork policy with no endorsement implication;
- best-effort support for the declared Windows x86-64 Hosted 1.0 scope;
- mandatory SHA-256 checksums and an owner-authorized release record, with
  detached cryptographic signatures optional.

The exact terms and procedures are in the root licensing/governance documents
and `release/RELEASE_AUTHORITY.md`.
