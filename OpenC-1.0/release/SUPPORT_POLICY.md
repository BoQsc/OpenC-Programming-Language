# Support policy

OpenC is provided without warranty under its applicable licenses. Project
support is best-effort and limited to the current 1.0 release line.

The initial supported implementation scope is the Windows x86-64 Hosted
reference toolchain recorded by the release evidence. Linux, freestanding,
Native, script/live, and Concurrent material may remain in the source tree for
future development but is experimental and nonblocking for 1.0.

Compatibility, maintenance duration, response time, and binary availability
are not guaranteed. Security and errata handling follow `SECURITY.md` and
`release/ERRATA_POLICY.md`.
