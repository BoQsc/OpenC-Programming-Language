# Licensing and Governance Remain Pending

HD-012 is intentionally unresolved. Before public release, the project owner or authorized governing body must select and record:

- normative standard license;
- implementation and tooling license;
- conformance corpus license;
- contribution terms;
- trademark/name policy if any;
- normative change authority;
- security-reporting channel;
- signing keys and release authorization;
- support and errata policy.

This package does not make legal choices on the owner's behalf and therefore cannot be RELEASE_READY or RELEASED.
