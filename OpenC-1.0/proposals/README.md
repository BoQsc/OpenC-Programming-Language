
# OpenC proposals

A proposal is non-normative until accepted and integrated.

Each proposal must contain:

```text
proposal.md
metadata.json
rationale.md
grammar_patch.ebnf
rule_patch.json
compatibility.md
implementation_plan.md
fixtures/
```

Required statuses:

```text
draft
experimental
accepted
rejected
withdrawn
superseded
```

Accepted status alone does not modify the standard; accepted work moves to `changes/` and is then integrated deliberately.
