
# Development lifecycle

```text
finding or idea
  ↓
triage: defect, clarification, proposal, or no action
  ↓
authored proposal/correction
  ↓
grammar + rules + diagnostics + compatibility + fixtures + implementation plan
  ↓
review
  ↓
accepted change
  ↓
integration into the current tree
  ↓
local structural checks and recorded execution when available
  ↓
versioned source snapshot
```

Direct normative edits are limited to obvious editorial corrections and urgent security defects. Any semantic expansion or compatibility change uses the proposal process.
