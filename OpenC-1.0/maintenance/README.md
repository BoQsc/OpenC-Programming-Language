
# OpenC maintenance

Maintenance preserves one canonical authority while allowing disciplined evolution.

Use:

- `DEVELOPMENT_LIFECYCLE.md` for end-to-end change flow;
- `PROPOSAL_PROCESS.md` for non-normative work;
- `ACCEPTED_CHANGE_PROCESS.md` for integration;
- `AUTHORITY_POLICY.md` for conflict resolution;
- `VERSIONING_AND_COMPATIBILITY.md` for version impact;
- `FINDING_AND_ERRATA_PROCESS.md` for defects;
- `SECURITY_MAINTENANCE.md` for security findings.
