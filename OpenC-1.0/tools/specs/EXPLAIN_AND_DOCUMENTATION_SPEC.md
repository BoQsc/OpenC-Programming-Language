# Rule Explanation and Documentation Tools

`openc explain RULE-ID` resolves one active or retired rule ID and shows:

```text
title
current status
normative text location
summary
valid examples
invalid examples
related rules
successor/predecessor IDs
security notes
conformance fixtures
```

Documentation generation consumes the authoritative standard, rule index, diagnostic catalog, terminology index, and examples. It rejects broken rule references and historical syntax presented as valid Core.
