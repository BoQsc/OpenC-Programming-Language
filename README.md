# OpenC

OpenC is a safe-by-default systems programming language with a self-hosted compiler, standard library, and executable conformance suite.

The canonical OpenC 1.0 development tree is in [`OpenC-1.0/`](OpenC-1.0/). Start with its [README](OpenC-1.0/README.md).

Source code uses the `.p` extension. See the [license policy](OpenC-1.0/LICENSE_POLICY.md) for the 0BSD software, CC0 documentation, and separately licensed third-party material.
